BLOOMTEA WEBSITE
================

Files:
- index.html       Welcome / home page
- flavors.html     Guava, Parijat and Rose products
- contact.html     Contact + feedback form
- thankyou.html    Final thank-you page
- styles.css       Animated responsive design
- script.js        Feedback mailto handler
- assets/          Uploaded Bloomtea images

How to use:
1. Keep the folder structure unchanged.
2. Open index.html in a browser, or upload the complete folder to your hosting.
3. The feedback form opens the visitor's default email application and addresses bloomtea07@gmail.com.

Note:
A pure static website cannot silently send emails from a visitor's browser. For automatic server-side email delivery, connect the form to a backend/email service later.
